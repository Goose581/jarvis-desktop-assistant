# v1.6.0 release checklist — All-in-One edition

- [ ] Run `build_release.bat` on 64-bit Windows with Python 3.10+ and Inno Setup 6 available.
- [ ] Confirm `download_ollama.ps1` downloads `vendor\OllamaSetup.exe` and reports a valid Authenticode signature from Ollama Inc.
- [ ] Confirm tests and Python compilation pass before packaging.
- [ ] Confirm `output\JARVIS-Setup.exe` is produced and contains the Ollama installer (single-file first-time download).
- [ ] On a clean Windows test account, install J.A.R.V.I.S.; verify Ollama is installed without a separate manual installation.
- [ ] On a machine with Ollama already installed, verify Setup skips the Ollama installation.
- [ ] Launch J.A.R.V.I.S.; open AI Model Manager; refresh models; pull a small model; verify progress and completion.
- [ ] Activate the downloaded model and verify a chat request succeeds.
- [ ] Delete a non-active model and verify active model deletion is blocked.
- [ ] Confirm models remain in Ollama's model store after a J.A.R.V.I.S. app update.
- [ ] Confirm all six themes, Workspace tools, voice, timer chime, notes and auto-update behaviour remain intact.
- [ ] Only after Windows checks pass, publish release tag `v1.6.0` and attach `dist\JARVIS-Windows.zip`, its checksum, and `output\JARVIS-Setup.exe`.
